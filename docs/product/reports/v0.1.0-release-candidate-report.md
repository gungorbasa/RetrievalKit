## Result

The combined Swift and Python `v0.1.0` preview release candidate is
implemented and locally qualified. The root README is an evidence-led product
page with CI-enforced Phase 6 claim mappings. The root Swift package exposes
the five planned products, both three-slice Apple aggregates are packaged with
stable SwiftPM checksums, and both Python distributions are built for the
complete macOS arm64 CPython 3.10–3.14 matrix.

The release bundle validator returns `PASS` with `publication_ready=false`.
Publication remains fail-closed because the owner has not yet supplied a root
license, approved notices, or publication authorization, and Python's existing
MIT metadata has not been reconciled with a chosen root license. Provisioned
Phase 7 scheduled and release evidence plus a verified signed tag are also
required by the publication workflow.

## Artifact qualification

Two detached clean worktrees built the full matrix with empty target
directories and a fixed source epoch. Both roots produced the same 12 paths and
byte-identical contents:

- `VectorKitFFI.xcframework.zip`
- `VectorKitGraphFFI.xcframework.zip`
- `vectorkit` wheels for CPython 3.10, 3.11, 3.12, 3.13, and 3.14
- `vectorkit-graph` wheels for the same five interpreters

The first comparison correctly discovered nondeterministic XCFramework list
ordering and absolute checkout paths in maturin's embedded wheel SBOM. The
release builders now sort XCFramework library metadata, remap Rust source
paths, canonicalize wheel SBOM paths to `/workspace`, regenerate wheel
`RECORD`, and rewrite archives with fixed ordering and timestamps. A second
complete two-root build passed, and two independently assembled release bundles
were also byte-identical.

Every wheel was installed and smoke-tested in an isolated environment. With
both Python distributions installed, both import orders produced the required
mutual-exclusion diagnostic. Fresh Swift consumers independently built
`VectorKit`, `VectorKitGraph`, `EmbeddingKit`, and `VectorKitPipeline`; a
consumer that requested both native aggregates was rejected by the linker.
