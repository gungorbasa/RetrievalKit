# Migrating to RetrievalKit 0.1.0

`0.1.0` is the first preview, so there is no earlier package release to upgrade
from. Existing repository users should rebuild the Rust core and select the
products required by their application:

- Swift applications add the `RetrievalKit` package once and select
  `RetrievalKit`, `RetrievalKitGraph`, `EmbeddingKit`, and/or
  `RetrievalKitPipeline`. Base and graph products can coexist because they use
  one graph-capable native aggregate.
- Swift callers should replace `import RetrievalKitIngest` with
  `import RetrievalKit`; `TextChunker` is now part of the base product.
- Python applications install either `retrievalkit` or `retrievalkit-graph`.

Existing V1 and V2 base indexes remain readable. The next save writes the
current transactional, checksummed format. Validate or back up application data
before migration; do not edit snapshot files directly.
